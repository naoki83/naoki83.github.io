プライバシーポリシー

対象：アプリ「bikko-youtube」／制定日：2026年10月11日

1. このアプリについて

「bikko-youtube」（以下「本アプリ」）は、YouTubeチャンネル「ビッ子ちゃんの朝チャート」の運営者が、自分のチャンネルに動画を投稿するためだけに使う個人用ツールです。運営者以外の方の利用は想定していません。

2. 取得する情報と使い道

本アプリは、Googleアカウントの認証（OAuth）で、次の権限だけを使います。

  • YouTubeへの動画のアップロード（youtube.upload）：自動で作成した解説動画を、運営者のチャンネルにアップロードするため
  • YouTubeアカウントの閲覧（youtube.readonly）：同じ日に動画を重複して投稿しないよう、運営者のチャンネルの最近の投稿一覧を確認するため

上記以外の目的には使いません。広告、プロファイリング、販売などには一切使いません。

3. 情報の保存

認証で発行されるトークンは、運営者だけが管理する暗号化された保存領域（GitHub Actions の Secrets）に保存し、動画の投稿処理のときにだけ使います。YouTubeから取得した投稿一覧は、重複の確認に使ったあと保存しません。

4. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません（法令に基づく場合を除きます）。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。また、本アプリはYouTube API サービスを使用しており、YouTube 利用規約およびGoogle プライバシー ポリシーが適用されます。

6. アクセスの取り消し

本アプリへのアクセス許可は、Googleアカウントの「サードパーティのアクセス」からいつでも取り消せます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、YouTubeチャンネル「ビッ子ちゃんの朝チャート」の概要欄に記載の連絡先からお願いします。

8. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容はこのページに掲載した時点から有効になります。

Privacy Policy (English summary)
"bikko-youtube" is a personal tool used only by the owner of the YouTube channel "ビッ子ちゃんの朝チャート". It uses the youtube.upload scope to upload videos to the owner's own channel and the youtube.readonly scope to check the owner's recent uploads to avoid duplicate posts. Tokens are stored only in the owner's encrypted GitHub Actions secrets. No data is sold, shared with third parties, or used for advertising. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; the YouTube Terms of Service and Google Privacy Policy apply. Access can be revoked at any time at Google Account permissions.
